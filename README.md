# Proyecto-6-Booklist

Aplicación SPA desarrollada con Vue 3 para la gestión de libros. Incluye inicio de sesión, ingreso como invitado, listado dinámico de libros, filtros por autor y categoría, detalle con rutas anidadas, manejo de errores 404 y adaptación para su despliegue en GitHub Pages.

👉 Consulte la explicación completa y detallada en [README_Booklist.txt](README_Booklist.txt)
